# HomebrewFormula

This directory is managed automatically by GoReleaser.

The `owui-proxy.rb` formula file is generated and pushed here on every tagged
release by the [release workflow](../.github/workflows/release.yml).

To install via Homebrew:

```bash
brew tap varmakarthik12/owui-proxy https://github.com/varmakarthik12/owui-proxy
brew install owui-proxy
```
